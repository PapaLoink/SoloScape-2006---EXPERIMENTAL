# Classic interface assets

2004 (revision 274) sidebar artwork and layouts used by the client's "Classic interface" setting.

- `sideicons.png` (13 icons, 30x30), `miscgraphics.png`, `miscgraphics2.png` (36x36 cells) and `miscgraphics3.png` (25x25 cells): from `LostCityRS/Content` branch `274`, `sprites/`.
- `options.if` (Game Options) and `controls.if` (Player controls): from `LostCityRS/Content` branch `274`, `scripts/interface_options/interfaces/` and `scripts/interface_controls/interfaces/`.
